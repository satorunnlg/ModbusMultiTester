# Modbus TCP Multi-Tester

**Modbus TCP Multi-Tester** は、産業用通信プロトコル Modbus TCP の通信テストを行うためのエンジニア向けユーティリティツールです。

単一のアプリケーションで **Master (Client)** と **Slave (Server)** の両方の機能を持ち、複数のメモリ領域を同時に監視できる **MDI (Multiple Document Interface)** 形式を採用しています。現場での立上げ調整やトラブルシューティングを強力にサポートします。

## 主な機能

  * **デュアルモード:** ラジオボタン一つで「Master」と「Slave」を即座に切り替え可能。
  * **マルチモニタ (MDI):**
      * 「コイル」「保持レジスタ」など、異なるアドレス範囲を複数の子ウィンドウで同時に監視可能。
      * ウィンドウの整列機能（横並び・縦並び）を搭載。
  * **ネットワーク選択:**
      * PCに複数のLANポート（NIC）がある場合、通信に使用する送信元IPアドレスを明示的に指定可能。
  * **スレーブエミュレーション:**
      * Slaveモード時は、外部Masterからの書き込みを即座に反映。
      * 画面上のグリッドを編集することで、Masterへの応答値を動的に変更可能。
  * **高度なログ機能:**
      * 送受信したパケットをバイナリ (Hex Dump) 形式でログファイルに自動保存。
  * **使いやすいUI:**
      * Windows標準のIPアドレス入力ライクなカスタムコントロールを採用。
      * 高速通信時でもスムーズな操作を実現するデータバインディング実装。

## 動作環境

  * **OS:** Windows 10 / 11
  * **フレームワーク:** .NET 8.0 (Windows Forms)

## 開発環境・依存ライブラリ

  * Visual Studio 2022 (または .NET 8.0 対応のIDE)
  * **NModbus** (v3.x) - Modbusプロトコルスタック

## インストールとビルド

1.  このリポジトリをクローンします。
    ```bash
    git clone https://github.com/your-username/ModbusMultiTester.git
    ```
2.  Visual Studio で `ModbusMultiTester.sln` を開きます。
3.  NuGet パッケージの復元を行い、依存ライブラリ (`NModbus`) をインストールします。
4.  ソリューションをビルドします。

## 使い方

### 1\. 共通設定

  * 画面上部の **「モード」** で Master / Slave を選択します。
  * **「ソースIP」** で通信に使用するネットワークアダプタを選択します（Localhostでのテストも可能です）。

### 2\. Master モード (Client)

1.  接続先の **IPアドレス**、**ポート番号**、**スレーブID** を設定し、「接続」ボタンを押します。
2.  ツールバーの **「＋パネル追加」** を押し、モニタ画面を開きます。
3.  モニタ画面で **種別**（保持レジスタ等）、**開始アドレス**、**個数** を入力し、**「設定」** ボタンを押します。
4.  通信が開始され、値がグリッドに表示されます。

### 3\. Slave モード (Server)

1.  **待受ポート**、**ユニットID** を設定し、「待受開始」ボタンを押します。
2.  ツールバーの **「＋パネル追加」** を押し、監視したい領域を設定して **「設定」** ボタンを押します。
3.  グリッドが表示されます。Masterからの書き込みがあれば値が更新され、こちらで値を書き換えればMasterへの応答値が変わります。
